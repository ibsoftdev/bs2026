Apertura de puerto 9001 en el Security Group (sesión separada)

Abrir puerto 9001 en el SG si vas a acceder desde tu IP.
Este ajuste no se hace en la pantalla de creación del servicio ECS. Ahí solo se asocia el Security Group a la tarea. Las reglas de entrada (puertos, orígenes) se editan en una sesión aparte: consola EC2 → Grupos de seguridad. Así se puede abrir o restringir acceso HTTP a Forms sin recrear el servicio.
En producción, evitar 0.0.0.0/0 para el puerto 9001. Limitar origen a My IP o red corporativa.
NOTA IMPORTANTE: si temporalmente usas 0.0.0.0/0 en DEV, reemplázalo por la tabla exacta de acceso antes de pasar a QA/PROD:

Anexo Comandos AWS CLI (referencia admin)

Durante el levantamiento de forms-admin, la creación principal se hizo por consola. La CLI se usó para exportar configuración, diagnosticar red/ECR/EFS, abrir NFS y ECS Exec. Los mismos comandos aplican a forms-server cambiando nombres de servicio/contenedor/revisión.

Región usada: us-east-1. Cluster: forms_report. Archivos locales de respaldo: conf_json/forms-admin.json, conf_json/forms-server.json.

1. Exportar servicio y task definition

Función: respaldar y revisar redes, SG, IP pública y definición de tarea.

aws ecs describe-services \
  --cluster forms_report \
  --services forms-admin \
  --region us-east-1 \
  --output json \
  > conf_json/forms-admin-service.json

aws ecs describe-services \
  --cluster forms_report \
  --services forms-admin \
  --region us-east-1 \
  --query 'services[0].{taskDefinition:taskDefinition,networkConfiguration:networkConfiguration,desiredCount:desiredCount,enableExecuteCommand:enableExecuteCommand,subnets:networkConfiguration.awsvpcConfiguration.subnets,securityGroups:networkConfiguration.awsvpcConfiguration.securityGroups,assignPublicIp:networkConfiguration.awsvpcConfiguration.assignPublicIp}' \
  --output json \
  > conf_json/forms-admin-service-red.json

aws ecs describe-task-definition \
  --task-definition forms-admin:5 \
  --region us-east-1 \
  --query taskDefinition \
  --output json \
  > conf_json/forms-admin.json

2. Diagnosticar subnets y salida a Internet (error ECR)

Función: identificar subnets pub-* vs privadas y si la ruta es IGW o NAT. Útil ante GetAuthorizationToken / i/o timeout a ECR.

aws ec2 describe-subnets \
  --subnet-ids \
    subnet-01212efd4a9ce759b subnet-0d27c63b4c25eabe1 subnet-0f4f99dc20cbd7798 \
    subnet-0bf694b45c2cecab9 subnet-0db31aeca3adf4ee0 subnet-05b8ff497dca6e1e3 \
  --region us-east-1 \
  --query 'Subnets[*].{Id:SubnetId,Name:Tags[?Key==`Name`].Value|[0],Public:MapPublicIpOnLaunch,Az:AvailabilityZone}' \
  --output table

aws ec2 describe-route-tables \
  --filters Name=association.subnet-id,Values=subnet-01212efd4a9ce759b \
  --region us-east-1 \
  --query 'RouteTables[0].Routes[*].{Dest:DestinationCidrBlock,Gateway:GatewayId,Nat:NatGatewayId,State:State}' \
  --output table
Conclusión operativa: usar solo las 3 subnets pub-* + assignPublicIp=ENABLED (ruta 0.0.0.0/0 → igw-...).

3. Revisar Security Groups

Función: verificar reglas de entrada/salida del SG de la tarea y del EFS.

# SG de la tarea ECS
aws ec2 describe-security-groups \
  --group-ids sg-0e1787d32bac71fcd \
  --region us-east-1 \
  --output json

# SG del EFS (ESF-dev-sg / EFS-dev-sg)
aws ec2 describe-security-groups \
  --group-ids sg-0e39a7aa49ff6a22b \
  --region us-east-1 \
  --output json
El SG default | DO NOT USE (sg-04963b231db91fcf1) tenía 0 reglas de entrada y salida; no usarlo en servicios ECS.

4. Revisar mount targets de EFS

Función: confirmar IPs/subnets de montaje y SG asociado al filesystem.

aws efs describe-mount-targets \
  --file-system-id fs-08471cc88d2a8edc3 \
  --region us-east-1 \
  --output table

# Sustituir <fsmt-...> por un MountTargetId del comando anterior
aws efs describe-mount-target-security-groups \
  --mount-target-id <fsmt-...> \
  --region us-east-1

5. Abrir NFS 2049 desde ECS hacia EFS (fix aplicado)

Función: permitir montaje EFS desde tareas con SG forms-sg-ecs. Corrige mount.nfs4: Connection timed out.

aws ec2 authorize-security-group-ingress \
  --group-id sg-0e39a7aa49ff6a22b \
  --protocol tcp \
  --port 2049 \
  --source-group sg-0e1787d32bac71fcd \
  --region us-east-1
Origen: forms-sg-ecs (sg-0e1787d32bac71fcd) → destino EFS SG (sg-0e39a7aa49ff6a22b), puerto TCP 2049.
